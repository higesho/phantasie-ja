日本語化プロジェクト

Phantasie

ファンタジー 日本語化パッチ

GOG.com 版「Phantasie Memorial Set」に収録された DOS 版の「Phantasie」を日本語で遊べるようにする、非公式のファンメイドパッチです。 できごとの文、人物のせりふ、巻物、戦闘の知らせ、町の施設、キャラクター作成、呪文・品物・怪物の名前、メニューまで、ゲームの中の文章を日本語で表示します。 ゲームのフォルダにファイルを置くだけで日本語になり、消せば英語に戻ります。

ダウンロード（GitHub）

どんなゲーム？

ファンタジーは、1985年に SSI が発売した、ダグラス・ウッド作のロールプレイングゲームです。

ゲルノア島は妖術師ニカデマスに征服されました。かつて魔術師たちは、ニカデマスに立ち向かうために九つの魔法の指輪を鍛えています。冒険者の一行は島の町と迷宮を巡り、巻物に記された島の歴史を読み解きながら、ニカデマスの支配に挑みます。

最大6人の一行を作ります。種族は人間・ドワーフ・エルフ・ハーフリング・ノームのほか、ゴブリンやトロルなどの怪物からも選べます。

画面

入れ方

  1. ダウンロードした Phantasie_JP.zip の中身を、ゲームのフォルダ（Phantasie 1・Phantasie 2・Phantasie 3 の三つのフォルダがある場所）にそのまま展開します。
  2. Phantasie 1\DOSBOX\winmm.dll が増えれば、この作品は日本語になります。元からあるファイルは上書きしません。
  3. いつもどおり GOG Galaxy やショートカットから起動します。

外し方

  • Phantasie 1\DOSBOX\winmm.dll を消します。

セーブデータは英語版と共通です。日本語版と英語版を行き来しても、続きから遊べます。

遊ぶときの注意

  • メニューは矢印キーと Enter で選びます。Esc で戻ります。
  • 説明書を見て答える三択の質問が出ることがあります。質問には答えを表示します。「（答え：2番）」なら、2 のキーを押します。
  • 名前、合言葉、謎かけの答えは英字で入力します。
  • 絵に描かれた文字（題字、看板など）と、縦書きの短い略語は英語のままです。
  • 長い文が一字ずつ出る場面や、窓に一部が隠れた行では、途中まで英語で見えることがあります。
  • GOG.com 版に同梱の DOSBox 0.74-3 のほか、公式の DOSBox 0.72〜0.74 系に入れ替えても日本語になります。DOSBox Staging、DOSBox-X などでは英語のまま動きます。
  • 日本語にならないときは、DOSBox.exe のプロパティの「互換性」に設定がないか確かめ、あれば外してください。
